# New Landing Zócalo

Landing de Zócalo Digital (agencia web). HTML, CSS y JavaScript puros, sin build.

- `index.html`, `styles.css`, `script.js`: página principal
- `footer.css`, `footer.js`: footer con montañas en dither
- `assets/`: logos, capturas de plantillas de referencia y fuentes

Para verla en local: `python3 -m http.server 5210` dentro de esta carpeta.
